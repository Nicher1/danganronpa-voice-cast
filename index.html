WHAT'S NEW

Patch notes

Version history. Releases are newest first and collapsed until you open them.

v0.16Master-editable story memory and dossiersCurrent release⌄

Custom stopping-point recaps

The master can add, edit, and remove spoiler-safe custom story summaries from the Monopad. A special Chapter 3 entry records the search for Taka and Hifumi's missing bodies without revealing what happens next.

Protected built-in summaries

Every normal pre-Trial and Trial recap can now be edited by the master, but it cannot be deleted or saved empty.

Editable character files

The master can rewrite a character's Monopad description from either the character editor or the open dossier.

v0.15A genuinely separate Reworked interfacePrevious release⌄

Two complete presentations, one board

Original preserves the established interface. Reworked now uses the full Hope's Peak prototype composition, including its own header, Monokuma emblem, progress band, navigation, two-column casting workspace, actor cards, memorial, statistics, Monopad, and Admin presentation.

Your choice does not fork the data

Changing the interface only changes how the shared live board is presented. Assignments, locks, deaths, chapters, recordings, history, and database updates remain identical for everyone.

Phone layout included

The alternate interface collapses its library, cast cards, statistics, and Monopad into touch-friendly single-column layouts on smaller screens.

v0.14Switchable interface themes and live death totalsPrevious release⌄

Original or Reworked, on every device

Every visitor can follow the shared default or choose Original or Reworked for their own browser. Both appearances keep the complete live board and database.

Master-controlled default

Admin Tools can choose which theme new visitors receive without overriding anyone’s personal selection.

Death totals follow Memorial

An actor’s total now comes directly from their characters currently in Memorial. Reviving a character subtracts one; recording that character’s death again adds it back to the actor who held them.

v0.13Private activity historyPrevious release⌄

Seven-day master overview

Admin Tools records actor visits and shows each start time, end time, and duration on a private seven-day timeline.

Database health check

The host can send a lightweight database query and immediately confirm whether the shared project is awake.

Fresh voice library

The corrected official voice map now uses a new asset filename so an older browser cache cannot pair a practice transcript with the previous audio clip.

v0.12Monopad character files and recapsPrevious release⌄

Character dossiers

Every available board now includes public character files with larger artwork and short, surface-level biographies. Library cards also show the new artwork and description when expanded.

Progress-aware story memory

The Monopad recap only displays events already reached by the current chapter and Trial state. Earlier completed Trials are remembered, while a current Trial shows only that chapter’s pre-Trial events.

Anime episode memory

During Danganronpa 3, the Monopad follows the watch-order tracker and recalls only the immediately preceding episode.

v0.11Mobile layout and chapter predictionsPrevious release⌄

Phone-sized boards stay on screen

Navigation, cards, controls, statistics, Memorial layouts, and dialogs now shrink and wrap within narrow phone screens without creating a blank strip to the right.

Fresh predictions for every chapter

Each actor now begins a newly entered chapter with empty Victim and Blackened choices, while earlier chapter predictions remain available for history and Statistics.

Trial-based prediction locking

Victim and Blackened choices remain editable before the Trial, lock while the Trial is ongoing, and correctly reopen with a fresh chapter. Death results now respect whether they occurred before or during the Trial.

v0.10Live presence and leader emblemsPrevious release⌄

See who is online

An actor box now receives a subtle highlighted border and status dot while that actor’s account is logged in. The highlight clears automatically after logout or disconnection.

Hope and despair leader emblems

The current game’s strongest predictor receives the Hope’s Peak emblem, while the actor with the most assigned-character deaths carries a Monokuma face. Tied leaders share the relevant emblem.

Cleaner prediction labels

Prediction controls use clearer, neutral labels and explain when their totals are finalized.

Voice samples stay available

When a revealed character has no dedicated sample pack for the ideal chapter, their play button now uses the newest earlier spoiler-safe pack instead of disappearing.

Always-current pages

The site now detects an older cached build and reloads the current release automatically, keeping host, player, and viewer pages consistent after an update.

v0.9Anime watch boardPrevious release⌄

Anime-first layout

Danganronpa 3 replaces the voice-casting slots with compact prediction score cards, a current-episode tracker, and a color-coded Future Arc, Despair Arc, and Hope Arc watch-order guide.

Board leaders

The strongest predictor on the active board receives the Hope’s Peak emblem, while the actor with the most assigned-character deaths carries a Monokuma face. Voice-actor cards are ordered by their most recent locked-character activity.

The next title

The locked banner now names the immediately upcoming game without revealing anything beyond it.

v0.8.1Anime point calculationScoring adjustment⌄

Point calculation for anime guessing

Prediction totals now remain consistent when the anime completion state is changed and restored.

v0.8Series predictions and future boardsPrevious release⌄

Danganronpa 3 prediction board

The series now progresses from DR1 to DR2 and then directly to Danganronpa 3, skipping Ultra Despair Girls. Each episode has a “dies next” prediction and a suspected-killer prediction.

V3 prepared in advance

Danganronpa V3: Killing Harmony is preloaded as the next full killing-game board, with its complete student cast, Monokuma, and all five Monokubs ready behind the progression lock.

Series-wide statistics

Actor records now show per-game Victim, Blackened, death, and correct-guess totals for unlocked boards only, plus an all-series comparison chart.

Spoiler-safe progression

Player game pickers show only boards the host has unlocked, while the host retains the full progression controls in Admin Tools.

v0.7Voice safety and version historyPrevious release⌄

Pre-trial now means pre-trial

During the current chapter's Trial, previously revealed living characters use only field dialogue heard before that Trial. Trial testimony is excluded. Outside the Trial, the pool remains the previous chapter's strongest lines, including its completed Trial.

Compact versioned patch notes

Major changes are grouped into numbered releases, sorted newest first, and collapsed by default so the history stays easy to scan.

v0.6Multi-game boardDanganronpa 2 framework⌄

Goodbye Despair is ready behind a progression lock

Admin Tools can mark games complete, unlocking the next spoiler-safe board. Every window gets a game picker once DR2 is available, while each game preserves separate assignments, chapters, Trial state, predictions, Memorial, and population history.

v0.5Chapter play systemPredictions, results, statistics, and sync⌄

Victim and Blackened voting

Every actor receives two predictions per chapter. They can move them freely before the Trial; entering the Trial permanently locks that chapter's choices.

Persistent results without double scoring

Pre-Trial deaths can establish the Victim, the host can mark the Blackened from Memorial, and prediction markers stay visible after a character dies. Result snapshots prevent duplicate points.

Actor records and known population

The Statistics tab tracks correct Victim guesses, correct Blackened guesses, and historical character deaths separately. Its host-controlled chart shows Alive below Dead, with Unknown on top.

Shared, role-protected data

Predictions, results, graph values, and statistics persist through Supabase. Players can edit only their own current pre-Trial predictions; spectators remain read-only; graph and result controls remain host-only.
